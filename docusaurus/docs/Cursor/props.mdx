## Static Props

Static properties are set during initialization and cannot be modified later.

### `container` {#props.container}

- **Type:** `Element | window`
- **Default:** `window`
- The container where the custom cursor is active.  
  Use `window` for full-window activation.

```js
const cursor = new Cursor({
  container: document.getElementById('cursor-container'),
});
```

### `hideNative` {#props.hideNative}

- **Type:** `boolean`
- **Default:** `false`
- Hides the native cursor if set to `true`.

```js
const cursor = new Cursor({
  hideNative: true,
});
```

### `append` {#props.append}

- **Type:** `boolean`
- **Default:** `true`
- Appends the custom cursor element to the container.  
  Use `false` if you need only cursor logic and interactions without the visual DOM element.

```js
const cursor = new Cursor({
  append: false,
});
```

### `behavior` {#props.behavior}

- **Type:** `"default"` | `"path"`
- **Default:** `"default"`
- Defines how the cursor follows the native pointer  
  `default` — Cursor interpolates toward the current pointer position.  
  `path` — Cursor follows a smooth SVG path repeating the pointer trajectory.  
  Use `path` for decorative or expressive cursor effects.

  Path length uses [`easeCoords`](#props.easeCoords) and requires a **numeric** ease (spring falls back to `0.1` with a warning).

```js
const cursor = new Cursor({
  behavior: 'path',
});
```

### `transformModifier` {#props.transformmodifier}

- **Type:** `(coords: ICursorFullCoords) => string`
- **Default:**
  ```ts
  (coords) => `translate(${coords.x}px, ${coords.y}px)`;
  ```
- Modifier for the cursor transform.

```js
const cursor = new Cursor({
  transformModifier: (coords) =>
    `translate(${coords.x}px, ${coords.y}px) rotate(${coords.angle}deg)`,
});
```

## Mutable Props

Mutable properties can be updated at runtime using `.updateProps()`.

:::tip Adaptive props
To apply different values by viewport or device, use **[Responsive](/docs/base/Responsive/#example-with-module)** with this component as the source. Props will update automatically when breakpoints change.
:::

### `enabled` {#props.enabled}

- **Type:** `boolean`
- **Default:** `true`
- Enables or disables the custom cursor interactions.

```js
const cursor = new Cursor({
  enabled: false,
});

// change value
cursor.updateProps({
  enabled: true,
});
```

### `width` {#props.width}

- **Type:** `number | string`
- **Default:** `50`
- The initial width of the custom cursor. Supports css units like `px`, `rem`, `vw`, `vh`, `svh`.

```js
const cursor = new Cursor({
  width: 50,
});

// change value
cursor.updateProps({
  width: '3rem',
});
```

### `height` {#props.height}

- **Type:** `number | string`
- **Default:** `50`
- The initial height of the custom cursor. Supports css units like `px`, `rem`, `vw`, `vh`, `svh`.

```js
const cursor = new Cursor({
  height: 50,
});

// change value
cursor.updateProps({
  height: '3rem',
});
```

### `ease` {#props.ease}

- **Type:** `number | { stiffness: number; damping: number }` ([`TRafEase`](/docs/Raf/methods#add))
- **Default:** falls back to [`lerp`](#props.lerp) (`0.2`)
- Base ease for Raf interpolation. Used when channel eases are `'auto'`.
  - `number` — damp strength (higher = snappier)
  - `{ stiffness, damping }` — spring

```js
const cursor = new Cursor({
  ease: 0.2,
});

// spring
cursor.updateProps({
  ease: { stiffness: 100, damping: 10 },
});
```

### `lerp` {#props.lerp}

- **Type:** `number | { stiffness: number; damping: number }`
- **Default:** `0.2`
- **Deprecated.** Use [`ease`](#props.ease) instead. Still applied when `ease` is unset.

```js
const cursor = new Cursor({
  lerp: 0.2,
});
```

### `easeCoords` {#props.easeCoords}

- **Type:** `TRafEase | 'auto'`
- **Default:** `'auto'`
- Ease for cursor `x` / `y` (and path length when `behavior` is `'path'`).  
  `'auto'` uses [`ease`](#props.ease).

```js
const cursor = new Cursor({
  easeCoords: 0.15,
});

cursor.updateProps({
  easeCoords: { stiffness: 100, damping: 10 },
});
```

### `easeSize` {#props.easeSize}

- **Type:** `TRafEase | 'auto'`
- **Default:** `'auto'`
- Ease for cursor `width` / `height`.  
  `'auto'` uses [`ease`](#props.ease).

```js
const cursor = new Cursor({
  easeSize: 0.2,
});
```

### `easeAngle` {#props.easeAngle}

- **Type:** `TRafEase | 'auto'`
- **Default:** `'auto'`
- Ease for cursor `angle`.  
  `'auto'` uses [`ease`](#props.ease).

```js
const cursor = new Cursor({
  easeAngle: { stiffness: 100, damping: 6 },
});
```

### `easeVelocity` {#props.easeVelocity}

- **Type:** `TRafEase | 'auto'`
- **Default:** `'auto'`
- Ease for cursor `velocity` (also used when friction pulls velocity toward `0`).  
  `'auto'` uses [`ease`](#props.ease).

```js
const cursor = new Cursor({
  easeVelocity: 0.1,
});
```

### `autoStop` {#props.autoStop}

- **Type:** `boolean`
- **Default:** `true`
- Pauses the internal Raf loop when all named entries have settled within their `appx`.  
  Set to `false` if you need continuous rendering (e.g. for shaders or custom effects).

```js
const cursor = new Cursor({
  autoStop: true,
});

// change value
cursor.updateProps({
  autoStop: false,
});
```
