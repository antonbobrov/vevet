# Callbacks

<Head>
  <title>Timeline Callbacks | vevet.js</title>
</Head>

:::note
All **[Module callbacks](/docs/base/Module/#callbacks)** are available in this class.
:::

### `start`

Fired when linear progress is set to `0` (including via [`reset`](methods#reset)).

```ts
const tm = new Timeline({
  onStart: () => console.log('start'),
});
```

or:

```ts
const destruct = tm.on('start', () => console.log('start'));

// Cancel the callback
destruct();
```

### `update`

Fired on every progress change.

Provides both:

- `progress` — linear progress (`0 → 1`)
- `eased` — progress with easing applied

```ts
const tm = new Timeline({
  onUpdate: ({ progress, eased }) => {
    // progress — linear
    // eased — eased value
  },
});
```

or:

```ts
const destruct = tm.on('update', ({ progress, eased }) => {
  console.log('update', progress, eased);
});

// Cancel the callback
destruct();
```

This allows you to:

- use `progress` for logic,
- use `eased` for animation interpolation.

### `end`

Fired when linear progress reaches `1`.

```ts
const tm = new Timeline({
  onEnd: () => console.log('end'),
});
```

or:

```ts
const destruct = tm.on('end', () => console.log('end'));

// Cancel the callback
destruct();
```

### `reset`

Fired when [`reset()`](methods#reset) is called, before progress is set to `0`.

```ts

  onReset: () => console.log('reset'),
});
```

or:

```ts

// Cancel the callback

```

### `resume`

Fired when playback resumes after a pause via [`play()`](methods#play) or [`reverse()`](methods#reverse).

Emitted before `play` / `reverse`.

```ts
const tm = new Timeline({
  onResume: () => console.log('resume'),
});
```

or:

```ts
const destruct = tm.on('resume', () => console.log('resume'));

// Cancel the callback
destruct();
```
