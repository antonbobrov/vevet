## Mutable Props

Mutable properties can be updated at runtime using `.updateProps()`.

:::tip Adaptive props
To apply different values by viewport or device, use **[Responsive](/docs/base/Responsive/#example-with-module)** with this component as the source. Props will update automatically when breakpoints change.
:::

### `duration` {#props.duration}

- **Type:** `number`
- **Default:** `1000`
- Timeline duration in milliseconds. Only positive values are accepted.

```js
const tm = new Timeline({
  duration: 1000,
});

// change value
tm.updateProps({
  duration: 500,
});
```

### `ease` {#props.ease}

- **Type:** `TEasing | TSpring`
- **Default:** `inherited from core settings` - [see settings](/docs/core/customization#modifying-settings).
- Ease for timeline progression. Supports:
  - named easing types (e.g. `EaseInOutCubic`);
  - **cubic bezier** as `[x1, y1, x2, y2]` (e.g. `[0.25, 0.1, 0.25, 1]`);
  - a custom `(progress) => number` function;
  - a [`TSpring`](/docs/utils#spring) config (`{ stiffness, damping }`);
  - `false` for linear progress.  
    See [easing types](/docs/utils#easing-types) and [spring](/docs/utils#spring) for more information.

```js
import { Timeline, EaseInOutCubic } from 'vevet';

// built-in easing
const tm = new Timeline({
  ease: EaseInOutCubic,
});

// cubic bezier
const tmBezier = new Timeline({
  ease: [0.25, 0.1, 0.25, 1],
});

// spring
const tmSpring = new Timeline({
  ease: { stiffness: 120, damping: 14 },
});

// change value
tm.updateProps({
  ease: EaseOutCubic,
});
```

### `easing` {#props.easing}

:::warning Deprecated
Use [`ease`](#props.ease) instead. Still used as a fallback when `ease` is not set.
:::
