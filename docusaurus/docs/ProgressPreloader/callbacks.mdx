# Callbacks

<Head>
  <title>ProgressPreloader Callbacks | vevet.js</title>
</Head>

:::note
All **[Preloader callbacks](/docs/Preloader/callbacks)** (`loaded`, `requestHide`, `hide`, `hidden`, …) are available.  
[`loaded`](/docs/Preloader/callbacks#loaded) fires when smoothed [`progress`](accessors#progress) reaches `1`, after all resources are resolved and optional [`endDuration`](props#props.endduration) finish.
:::

### `progress`

Fired each animation frame while progress is updating (including the `endDuration` finish timeline).

```ts
const preloader = new ProgressPreloader({
  container: document.getElementById('container'),
  onProgress: (_data, { progress }) => console.log(progress),
});
```

or:

```ts
const destruct = preloader.on('progress', () =>
  console.log(preloader.progress),
);

// Cancel the callback
destruct();
```

### `resource`

Fired whenever a resource updates its loaded weight —  
both DOM-based (`data-loaded` changes) and virtual resources.

```ts
const preloader = new ProgressPreloader({
  container: document.getElementById('container'),
  onResource: ({ id, weight, loaded }) => {
    console.log(id, `loaded ${loaded} / ${weight}`);
  },
});
```

or:

```ts
const destruct = preloader.on('resource', ({ id, weight, loaded }) => {
  console.log(id, `loaded ${loaded} / ${weight}`);
});

// Cancel the callback
destruct();
```
