# Accessors

<Head>
  <title>Swipe Accessors | vevet.js</title>
</Head>

:::note
All **[Module accessors](/docs/base/Module/#accessors)** are available in this class.
:::

### `coords`

Type: **[ISwipeCoords](interfaces#iswipecoords)**

Full snapshot — pointer fields plus `movement`, `prevMovement`, `scale`.

```js
swipe.coords.movement.x;
swipe.coords.scale;
swipe.coords.diff.x;
```

### `container`

Type: `HTMLElement | SVGElement`

Coordinate reference element (`props.container`).

### `movement`

Type: **[ISwipeVec3](interfaces#iswipevec3)**

Total displacement in **movement space** (after rubber-band on [`bounds`](props#props.bounds)). Use for transforms with persistent pan, zoom, or snap UIs — snap itself lands via inertia / [`releaseRubber`](methods#releaserubber).

```js
swipe.on('move', ({ movement, scale }) => {
  el.style.transform = `translate(${movement.x}px, ${movement.y}px) scale(${scale})`;
});
```

### `scale`

Type: `number`

Current scale (default `1`). Updated by [`setScale`](methods#setscale).

### `start` / `prev` / `current`

Type: **[ISwipeState](interfaces#iswipestate)**

Pointer positions for this gesture (`x`, `y`, `angle`, `time`).

### `diff`

Type: **[ISwipeState](interfaces#iswipestate)**

Offset from gesture start to current pointer (pointer space). Great for one-shot drags that reset on release.

### `step`

Type: **[ISwipeState](interfaces#iswipestate)**

Offset from previous sample to current — useful for velocity and custom physics.

### `accum`

Type: **[ISwipeVec3](interfaces#iswipevec3)**

Absolute path length since gesture start (`|step|` per axis).

### `hasInertia`

Type: `boolean`

Whether release inertia is running.

### `hasRubber`

Type: `boolean`

Whether the release rubber / snap settle timeline is running.

### `isSwiping`

Type: `boolean`

Whether an active swipe is in progress (`start` has fired).
