# Methods

<Head>
  <title>Swipe Methods | vevet.js</title>
</Head>

:::note
All **[Module methods](/docs/base/Module/#methods)** are available in this class.
:::

### `calculateBounds`

Re-reads [`bounds`](props#props.bounds) and caches `[min, max]` per axis. Runs automatically on move; call after layout changes outside a gesture (e.g. resize).

```ts
swipe.calculateBounds();
```

### `setScale`

Sets scale in movement space. Pass an **origin** (`MouseEvent`, `TouchEvent`, or `{ x, y }` in client coords) to zoom toward a point. Emits `move`. When inertia is idle, settles with [`releaseRubber(0)`](#releaserubber).

```ts
import { clamp } from 'vevet';

wrapper.addEventListener(
  'wheel',
  (event) => {
    event.preventDefault();
    swipe.setScale(clamp(swipe.scale - event.deltaY * 0.001, 1, 3), event);
  },
  { passive: false },
);
```

### `setMovement`

Sets displacement in movement space, emits `move`, then [`releaseRubber(0)`](#releaserubber).

```ts
swipe.setMovement({ x: 100, y: 50 });
swipe.setMovement({ angle: 45 });
```

### `releaseRubber`

Starts release settle: nearest [`snap`](props#props.snap) target when available, otherwise pulls back inside [`bounds`](props#props.bounds) when [`overscroll`](props#props.overscroll) allows it. [`canRubber`](props#props.canrubber) gates the entire settle (snap + exceeds).

Called automatically after gesture end when inertia does not run. Pass `0` for an instant settle (used by `setScale` / `setMovement`).

```ts
swipe.releaseRubber(); // animated
swipe.releaseRubber(0); // instant
```

### `cancelRubber`

Stops the release settle timeline.

```ts
swipe.cancelRubber();
```

### `cancelInertia`

Stops release inertia.

```ts
swipe.cancelInertia();
```

### `destroy`

Removes listeners and stops inertia / rubber settle.

```ts
swipe.destroy();
```
