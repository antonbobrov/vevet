## Static Props

Set once at creation — cannot change later.

### `container` {#props.container}

- **Type:** `HTMLElement | SVGElement`
- Element used for coordinates and event attachment.

```js
const swipe = new Swipe({
  container: document.getElementById('container'),
});
```

### `thumb` {#props.thumb}

- **Type:** `HTMLElement | SVGElement | null`
- **Default:** `null`
- Grab handle. Coordinates still use `container` — `thumb` only decides where the user can start the drag.
- **See [demo](demos#lever-rotation)**

```js
const swipe = new Swipe({
  container: document.getElementById('container'),
  thumb: document.getElementById('thumb'),
});
```

### `buttons` {#props.buttons}

- **Type:** `number[] | ((type: TPointersType) => number[])`
- **Default:** `[0]`
- Which mouse buttons start a drag (`0` left, `2` right, …). Same shape as [`Pointers` `buttons`](/docs/Pointers/props#props.buttons).
- **See [demo](demos#right-click-drag)**

```js
const swipe = new Swipe({
  container: document.getElementById('container'),
  buttons: [0, 2],
});
```

```js
buttons: (type) => (type === 'touch' ? [0] : [2]),
```

### `pointers` {#props.pointers}

- **Type:** `number | ((type: TPointersType) => number)`
- **Default:** `1`
- How many pointers must be down to start. Movement follows the **center** between them.
- **See [demo](demos#two-fingers-pan)**

```js
pointers: 2,
// or
pointers: (type) => (type === 'mouse' ? 1 : 2),
```

### `disableUserSelect` {#props.disableUserSelect}

- **Type:** `boolean`
- **Default:** `true`
- Disables text selection while dragging.

## Mutable Props

Change anytime with `.updateProps()`.

:::tip Adaptive props
Use **[Responsive](/docs/base/Responsive/#example-with-module)** to switch values by viewport or device.
:::

### `enabled` {#props.enabled}

- **Type:** `boolean`
- **Default:** `true`
- Turns swipe on or off.

### `relative` {#props.relative}

- **Type:** `boolean`
- **Default:** `false`
- Coordinates relative to the container instead of the page.
- **See [demo](demos#rotation-swipe)**

### `axis` {#props.axis}

- **Type:** `null | 'x' | 'y'`
- **Default:** `null`
- Locks the gesture to one axis. Wrong direction → [`abort`](callbacks#abort).
- **See [demo](demos#basic-demo)**

### `ratio` {#props.ratio}

- **Type:** `number`
- **Default:** `1`
- Multiplies pointer steps when building `movement`.

### `grabCursor` {#props.grabCursor}

- **Type:** `boolean`
- **Default:** `false`
- Shows grab / grabbing cursors on `thumb` or `container`.

### `willAbort` {#props.willAbort}

- **Type:** `(props: ISwipeCanMoveArg) => boolean`
- **Default:** `() => false`
- Return `true` to block the gesture before `start`.

```js
willAbort: ({ diff }) => Math.abs(diff.x) < Math.abs(diff.y),
```

### `threshold` {#props.threshold}

- **Type:** `number`
- **Default:** `5`
- Minimum pointer travel (px) before `start`.

### `minTime` {#props.minTime}

- **Type:** `number`
- **Default:** `0`
- Minimum hold time (ms) before the swipe can activate.

### `directionThreshold` {#props.directionThreshold}

- **Type:** `number`
- **Default:** `50`
- Minimum distance (px) for `toLeft` / `toRight` / `toTop` / `toBottom`.

### `preventEdgeSwipe` {#props.preventEdgeSwipe}

- **Type:** `boolean`
- **Default:** `false`
- Blocks iOS-style edge swipe-back near the screen edge.

### `edgeSwipeThreshold` {#props.edgeSwipeThreshold}

- **Type:** `number`
- **Default:** `20`
- Edge zone size (px) for `preventEdgeSwipe`.

### `preventTouchMove` {#props.preventTouchMove}

- **Type:** `boolean`
- **Default:** `true`
- Calls `preventDefault` on `touchmove` so the page does not scroll while dragging.

### `requireCtrlKey` {#props.requireCtrlKey}

- **Type:** `boolean`
- **Default:** `false`
- Mouse only — require Ctrl to drag.

### `bounds` {#props.bounds}

- **Type:** `null | ((coords: ISwipeCoords) => ISwipeAxes | null)`
- **Default:** `null`
- Movement limits per axis (`[min, max]`). Unset axis = free.
- Receives full [`ISwipeCoords`](interfaces#iswipecoords) — use `scale` for zoom-aware viewers.
- **See [demo](demos#drag-inertia-bounce)**

```js
bounds: ({ scale }) => ({
  x: [0, wrapper.clientWidth - thumb.clientWidth * scale],
  y: [0, wrapper.clientHeight - thumb.clientHeight * scale],
}),
```

### `overscroll` {#props.overscroll}

- **Type:** `number | (() => number)`
- **Default:** `50`
- How far past `bounds` the drag can stretch (rubber-band).
- `0` = hard clamp while dragging and no exceeds settle.
- **See [demo](demos#drag-inertia-bounce)**

```js
overscroll: 80,
```

### `canRubber` {#props.canRubber}

- **Type:** `() => boolean`
- **Default:** `() => true`
- When `false`, skips the entire [`releaseRubber`](methods#releaserubber) settle — both snap and exceeds. Inertia can still run.

### `rubberDuration` {#props.rubberDuration}

- **Type:** `number`
- **Default:** `250`
- Duration (ms) of release settle when inertia does not run.

### `rubberEase` {#props.rubberEase}

- **Type:** `TEasing | TSpring`
- **Default:** `EaseOutCubic`
- Ease for release settle (snap or back inside bounds).

### `snap` {#props.snap}

- **Type:** `null | (() => ISwipeAxes | null)`
- **Default:** `null`
- Target positions per axis. On release, inertia distance and [`releaseRubber`](methods#releaserubber) prefer the nearest target.

```js
snap: () => ({ x: [0, 100, 200, 300] }),
```

### `boundsOnInertia` {#props.boundsOnInertia}

- **Type:** `boolean`
- **Default:** `true`
- Re-read `bounds` while inertia runs. Set `false` for static limits to skip extra work.

### `inertia` {#props.inertia}

- **Type:** `boolean`
- **Default:** `false`
- Coast after release (RAF velocity decay).
- **See [demo](demos#drag-inertia)**

### `inertiaEase` {#props.inertiaEase}

- **Type:** `number`
- **Default:** `0.05`
- How quickly freeflow velocity dies (higher = stops sooner).
- **See [demo](demos#inertia-settings)**

### `inertiaRubberEase` {#props.inertiaRubberEase}

- **Type:** `TRafEase` (`number` damp or spring)
- **Default:** `0.3`
- How inertia pulls back inside `bounds` after overscroll.
- **See [demo](demos#inertia-settings)**

### `inertiaRatio` {#props.inertiaRatio}

- **Type:** `number`
- **Default:** `1`
- Extra release-velocity multiplier.

### `inertiaThreshold` {#props.inertiaThreshold}

- **Type:** `number`
- **Default:** `1`
- Minimum release speed to start inertia (px/s or deg/s). Below → `inertiaFail`.

### `inertiaMaxVelocity` {#props.inertiaMaxVelocity}

- **Type:** [`ISwipeVec3`](interfaces#iswipevec3)
- **Default:** `{ x: 7, y: 7, angle: 3 }`
- Caps release velocity (coord/ms). Falsy axis disables inertia on that axis.

### `modifyInertiaDistance` {#props.modifyInertiaDistance}

- **Type:** `null | ((distance: ISwipeVec3) => ISwipeVec3 | null)`
- **Default:** `null`
- Override predicted freeflow travel. Returning a vector switches inertia to distance mode. Snap may still redirect the end per axis.
- **See [demo](demos#inertia-distance-modifier)**

```js
modifyInertiaDistance: (distance) => ({
  x: Math.max(-100, Math.min(100, distance.x)),
  y: distance.y,
  angle: 0,
}),
```

## Deprecated aliases

Old names still resolve. Prefer the props above.

| Deprecated                                    | Use instead                                             |
| --------------------------------------------- | ------------------------------------------------------- |
| `overflow`                                    | [`overscroll`](#props.overscroll)                       |
| `canBounce` / `allowRubber`                   | [`canRubber`](#props.canrubber)                         |
| `bounceDuration`                              | [`rubberDuration`](#props.rubberduration)               |
| `easeRubber`                                  | [`rubberEase`](#props.rubberease)                       |
| `recalculateBoundsOnInertia`                  | [`boundsOnInertia`](#props.boundsoninertia)             |
| `inertiaDecay`                                | [`inertiaEase`](#props.inertiaease)                     |
| `inertiaBounceEase` / `easeOverflow`          | [`inertiaRubberEase`](#props.inertiarubberease)         |
| `maxVelocity`                                 | [`inertiaMaxVelocity`](#props.inertiamaxvelocity)       |
| `inertiaDistanceModifier` / `inertiaDistance` | [`modifyInertiaDistance`](#props.modifyinertiadistance) |
| `snapRadius`                                  | unused — nearest snap is always used                    |

Timelined inertia props (`inertiaDuration`, `inertiaEasing`, `velocityModifier`, `inertiaDistanceThreshold`) are no longer supported.
