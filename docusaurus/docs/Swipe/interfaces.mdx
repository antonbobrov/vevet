## ISwipeVec2

2D vector in swipe coordinate space.

```ts
interface ISwipeVec2 {
  x: number;
  y: number;
}
```

## ISwipeVec3

2D vector plus rotation (`angle` in degrees).

```ts
interface ISwipeVec3 extends ISwipeVec2 {
  angle: number;
}
```

## ISwipeState

Pointer sample: position plus `time` (ms, `performance.now()`).

```ts
interface ISwipeState extends ISwipeVec3 {
  time: number;
}
```

## ISwipeAxes

Optional value lists per axis — used by [`bounds`](props#props.bounds) and [`snap`](props#props.snap).

```ts
interface ISwipeAxes {
  x?: number[];
  y?: number[];
  angle?: number[];
}
```

## ISwipeCoords

Snapshot on callbacks and accessors. See [Two coordinate spaces](/docs/Swipe#two-coordinate-spaces).

- **Pointer space:** `start`, `prev`, `current`, `diff`, `step`, `accum`
- **Movement space:** `movement`, `prevMovement`, `scale` — after rubber-band; use for transforms with bounds / zoom / snap UIs

```ts
interface ISwipeCoords {
  timestamp: number;
  start: ISwipeState;
  prev: ISwipeState;
  current: ISwipeState;
  diff: ISwipeState;
  step: ISwipeState;
  accum: ISwipeVec3;
  movement: ISwipeVec3;
  prevMovement: ISwipeVec3;
  scale: number;
}
```

## ISwipeCanMoveArg

Arguments for [`willAbort`](props#props.willAbort).

```ts
interface ISwipeCanMoveArg {
  type: 'touch' | 'mouse';
  state: ISwipeState;
  start: ISwipeVec2;
  diff: ISwipeVec2;
}
```
