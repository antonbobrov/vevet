# Methods

<Head>
  <title>Raf Methods | vevet.js</title>

:::note
All **[Module methods](/docs/base/Module/#methods)** are available in this class.
:::

### `lerpFactor`

Frame-rate–independent interpolation factor for the last [`duration`](accessors#duration).

Non-finite `ease` falls back to `1`.

**See [demo](demos#damping)**

```ts
const ease = raf.lerpFactor(0.1);
lerp(from, to, ease);
```

### `damp`

Shorthand for `lerp(from, to, raf.lerpFactor(ease))` on the instance.

**See [demo](demos#damping)**

```ts
value = raf.damp(value, target, 0.1);
```

### `pause`

Pauses the animation loop.

```ts
raf.pause();
```

### `play`

Starts the animation loop.

```ts
raf.play();
```

### `destroy`

Destroys the instance and cleans up resources.

```ts
raf.destroy();
```
