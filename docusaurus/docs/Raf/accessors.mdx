# Accessors

<Head>
  <title>Raf Accessors | vevet.js</title>
</Head>

:::note
All **[Module accessors](/docs/base/Module/#accessors)** are available in this class.
:::

### `isPlaying`

Type: `boolean`

Whether the rAF chain is active (`enabled` and not paused).

```js
const raf = new Raf();

raf.isPlaying; // true or false
```

### `timestamp`

Type: `number`

High-resolution timestamp of the last processed frame. **See [demo](demos#info)**

```js
const raf = new Raf();

raf.timestamp; // returns timestamp
```

### `index`

Type: `number`

Count of processed frames since the last `enabled` / `fps` reset. **See [demo](demos#info)**

```js
const raf = new Raf();

raf.index; // returns frame index
```

### `fps`

Type: `number`

Estimated real-time FPS (recalculated every [`fpsRecalcFrames`](props#props.fpsRecalcFrames)). **See [demo](demos#info)**

```js
const raf = new Raf();

raf.fps; // returns real-time fps
```

### `duration`

Type: `number`

Duration of the last processed frame in ms.

```js
const raf = new Raf();

raf.duration; // returns duration of the last frame in ms
```

### `fpsFactor`

Type: `number`

Multiplier `60 / fps` for physics tuned to a 60 Hz baseline.

Useful for making physics and easing consistent regardless of monitor refresh rate.

**See [demo](demos#info)**

```js
const raf = new Raf();

raf.fpsFactor; // returns scaling coefficient
```
