# Raf

`requestAnimationFrame` loop with FPS throttling and frame-rate–independent easing:

- Schedules a rAF chain while [`enabled`](props#props.enabled) is true
- Throttles logical frames via [`fps`](props#props.fps) (fixed cap or `'auto'`)
- Measures real-time [`fps`](accessors#fps), [`duration`](accessors#duration), and frame [`index`](accessors#index)
- Provides [`lerpFactor`](methods#lerpfactor) and [`damp`](methods#damp) for refresh-rate–independent motion

## Animation loop

1. **`play`** / `enabled: true` — starts the rAF chain; emits [`play`](callbacks#play) and [`toggle`](callbacks#toggle).
2. **`frame`** — fired on each **processed** frame (after FPS throttling), with `fps`, `fpsFactor`, `duration`, and `lerpFactor`.
3. **`pause`** / `enabled: false` — `cancelAnimationFrame`; emits [`pause`](callbacks#pause) and [`toggle`](callbacks#toggle).

Changing [`fps`](props#props.fps) or [`enabled`](props#props.enabled) resets frame timing.

## Initialization

Raf is easy to initialize:

```js
import { Raf } from 'vevet';

const raf = new Raf({ enabled: true });

raf.on('frame', () => {
  console.log('your logic');
});
```

Disabled by default:

```js
import { Raf } from 'vevet';

const raf = new Raf({
  enabled: false,
});
```

Predefined FPS or adaptive FPS:

```js
import { Raf } from 'vevet';

const raf = new Raf({
  enabled: true,
  fps: 'auto', // or fps: [number]
});
```

Get real-time FPS:

```js
import { Raf } from 'vevet';

const raf = new Raf({
  enabled: true,
  fps: 30,
  onFrame: ({ fps }) => {
    console.log(fps);
  },
});
```

Damping — use [`damp`](methods#damp) or [`lerpFactor`](methods#lerpfactor) for consistent motion across 60 Hz, 120 Hz, and 144 Hz displays (**see [demo](demos#damping)**):

```ts
raf.on('frame', () => {
  value = raf.damp(value, target, 0.1);
});
```

Play:

```ts
raf.play();
```

Pause:

```ts
raf.pause();
```

Destroy the Raf instance:

```js
raf.destroy();
```
