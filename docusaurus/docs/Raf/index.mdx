# Raf

`requestAnimationFrame` loop with FPS throttling and frame-rate–independent easing:

- Schedules a rAF chain while [`enabled`](props#props.enabled) is true
- Throttles logical frames via [`fps`](props#props.fps) (fixed cap or `'auto'`)
- Measures real-time [`fps`](accessors#fps), [`duration`](accessors#duration), and frame [`index`](accessors#index)
- Provides [`lerpFactor`](methods#lerpfactor) and [`damp`](methods#damp) for refresh-rate–independent motion
- Named entries via [`add`](methods#add) / [`value`](methods#value) / [`target`](methods#target) / [`sync`](methods#sync) / [`delete`](methods#delete) / [`interpolated`](methods#interpolated): damp (`ease: number`) or spring (`ease: { stiffness, damping }`), optional `friction` (pull numeric target toward `0` with the same `ease`), updated each processed frame before [`frame`](callbacks#frame)

## Animation loop

1. **`play`** / `enabled: true` — starts the rAF chain; emits [`play`](callbacks#play) and [`toggle`](callbacks#toggle).
2. **`frame`** — fired on each **processed** frame (after FPS throttling), with `fps`, `fpsFactor`, `duration`, and `lerpFactor`. Named entries are interpolated before this callback.
3. **`pause`** / `enabled: false` — `cancelAnimationFrame`; emits [`pause`](callbacks#pause) and [`toggle`](callbacks#toggle).

Changing [`fps`](props#props.fps) or [`enabled`](props#props.enabled) resets frame timing.

## Initialization

Raf is easy to initialize:

```js
import { Raf } from 'vevet';

const raf = new Raf({ enabled: true });

raf.on('frame', () => {
  console.log('your logic');
});
```

Disabled by default:

```js
import { Raf } from 'vevet';

const raf = new Raf({
  enabled: false,
});
```

Predefined FPS or adaptive FPS:

```js
import { Raf } from 'vevet';

const raf = new Raf({
  enabled: true,
  fps: 'auto', // or fps: [number]
});
```

Get real-time FPS:

```js
import { Raf } from 'vevet';

const raf = new Raf({
  enabled: true,
  fps: 30,
  onFrame: ({ fps }) => {
    console.log(fps);
  },
});
```

Damping — use [`damp`](methods#damp) or [`lerpFactor`](methods#lerpfactor) for consistent motion across 60 Hz, 120 Hz, and 144 Hz displays (**see [demo](demos#damping)**):

```ts
raf.on('frame', () => {
  value = raf.damp(value, target, 0.1);
});
```

Named entries — [`add`](methods#add) once, then [`target`](methods#target) / [`value`](methods#value) to update (starts the loop via [`play`](methods#play)):

```ts
raf.add('x', { value: 0, ease: 0.1 });
raf.add('y', {
  value: 0,
  ease: { stiffness: 100, damping: 10 },
});
raf.add('velocity', { value: 0, ease: 0.1, friction: true });

raf.target('x', pointer.x);
raf.target('y', pointer.y);
raf.target('velocity', speed);

raf.on('frame', () => {
  const x = raf.value('x');
  const y = raf.value('y');

  if (raf.interpolated()) {
    raf.pause();
  }
});
```

Play:

```ts
raf.play();
```

Pause:

```ts
raf.pause();
```

Destroy the Raf instance:

```js
raf.destroy();
```
