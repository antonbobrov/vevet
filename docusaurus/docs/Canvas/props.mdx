## Static Props

Static properties are set during initialization and cannot be modified later.

### `container` {#props.container}

- **Type:** `HTMLElement | null`
- **Default:** `null`
- Parent element used to determine canvas size. If `null`, it uses the viewport.

```js
const canvas = new Canvas({
  container: document.getElementById('container'),
});
```

### `append` {#props.append}

- **Type:** `boolean`
- **Default:** `true`
- If `true`, appends the canvas to the `container`. Ignored if `container` is `null`.

```js
const canvas = new Canvas({
  append: false,
});
```

### `resize` {#props.resize}

- **Type:** `ICanvasStaticPropsResize | false`
- **Default:** `{ init: true, runtime: false, target: 'any', debounce: 0 }`
- Resize behavior. Pass `false` to disable auto-resize on init and runtime.

| Field | Type | Default | Description |
| --- | --- | --- | --- |
| `init` | `boolean` | `true` | Resize once on initialization. |
| `runtime` | `boolean` | `false` | Resize on viewport/container changes. |
| `target` | viewport event | `'any'` | Which dimension(s) trigger resize. [Learn more](/docs/core/features#vevetonresize) |
| `debounce` | `number` | `0` | Debounce time (ms). |

```js
const canvas = new Canvas({
  resize: {
    init: true,
    runtime: true,
    target: 'any',
    debounce: 0,
  },
});
```

### Deprecated resize props

Prefer [`resize`](#propsresize). These flat aliases still work when set:

- `resizeOnInit` → `resize.init`
- `resizeOnRuntime` → `resize.runtime`
- `viewportTarget` → `resize.target`
- `resizeDebounce` → `resize.debounce`

## Mutable Props

Mutable properties can be updated at runtime using `.updateProps()`.

:::tip Adaptive props
To apply different values by viewport or device, use **[Responsive](/docs/base/Responsive/#example-with-module)** with this component as the source. Props will update automatically when breakpoints change.
:::

### `width` {#props.width}

- **Type:** `'auto' | number`
- **Default:** `'auto'`
- Canvas width. Use `'auto'` to match the container's width.

```js
const canvas = new Canvas({
  width: 'auto',
});

// change value
canvas.updateProps({
  width: 100,
});
```

### `height` {#props.height}

- **Type:** `'auto' | number`
- **Default:** `'auto'`
- Canvas height. Use `'auto'` to match the container's height.

```js
const canvas = new Canvas({
  height: 'auto',
});

// change value
canvas.updateProps({
  height: 100,
});
```

### `dpr` {#props.dpr}

- **Type:** `'auto' | number`
- **Default:** `'auto'`
- Device Pixel Ratio (DPR). Use `'auto'` for automatic detection.

```js
const canvas = new Canvas({
  dpr: 'auto',
});

// change value
canvas.updateProps({
  dpr: 100,
});
```
