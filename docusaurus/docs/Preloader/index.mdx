# Preloader

Page preloader — loading screen visibility and lifecycle:

- Waits for page load (`loaded`)
- Optional auto-hide when [`hide`](props#props.hide) is a duration
- Fades [`container`](props#props.container) opacity via `Timeline`

Does not provide styling for the container.

## Lifecycle

1. **`loaded`** — page is ready (`initVevet().onLoad`; overridable in [`ProgressPreloader`](/docs/ProgressPreloader)).
2. **`requestHide`** — hide is requested; use for custom hide timing when [`hide: false`](props#props.hide).
3. **`hide`** — fade starts (automatic when `hide` is a number, or via [`hide()`](methods#hide)).
4. **`hidden`** — fade completed; [`isHidden`](accessors#ishidden) is `true`.

When `hide: false`, call `hide(duration)` manually — typically from [`requestHide`](callbacks#requesthide).  
When `container: null`, only callbacks fire — no DOM animation.

## Initialization

:::caution
The module does not provide styling for the container.
:::

```html
<div id="preloader">Loading...</div>
```

```css
#preloader {
  position: fixed;
  top: 0;
  left: 0;
  width: 100%;
  height: 100%;
  z-index: 9;

  display: flex;
  flex-direction: column;
  align-items: center;
  justify-content: center;
}
```

```js
import { Preloader } from 'vevet';

const preloader = new Preloader({
  container: document.getElementById('preloader'),
  hide: 700,
});
```

Destroy the preloader:

```js
preloader.destroy();
```
