Class Preloader<C, S, M>

Page preloader — loading screen visibility and lifecycle.

  • Waits for page load via _onLoaded (overridable by ProgressPreloader)
  • Optional auto-hide when hide is a duration in milliseconds
  • Fades container opacity via Timeline

Does not provide styling for the container.

Lifecycle

loaded → hide (auto or manual) → container fade → hidden

When hide is false, call hide manually after load. When container is null, only events fire — no DOM animation.
